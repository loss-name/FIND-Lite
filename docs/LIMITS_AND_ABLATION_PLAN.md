# 消融与极限测试计划

## 先验约束

发布级测试不以单一函数、单一维度或有利种子判断。任何改进都必须同时报告其对单峰精度、
平移多峰和高维 Rosenbrock 的影响。

## 消融矩阵

1. 默认 `FIND_Lite`；
2. 普通独立三锚点（无尺度下限、无端点续行）；
3. 退火 Lite；
4. DE/rand/1/bin；
5. gbest PSO。

默认函数为平移 Ackley、平移 Rastrigin、30维 Rosenbrock、Sphere。每项30种子，
预算`500d`。新机制必须新增一行，不能覆盖默认 Lite 的结果。

## 极限扫描

分两阶段，避免在尚未验证正确性前耗尽计算资源。

### 阶段一：边界定位

- 维度：2、5、10、30、50、100、200；
- 预算：`50d`、`100d`、`500d`、`1000d`；
- 函数：Sphere、旋转病态二次、平移 Ackley、30维以上 Rosenbrock；
- 每格10个种子。

输出为“维度—预算—中位数—四分位区间”曲线，重点标出：无法达到预先定义精度、方差
突然增大、预算不再带来明显改进的区域。

### 阶段二：确认

对阶段一中 FIND 有优势、与 DE/PSO 持平、以及明显失败的三个代表区域，增加到30种子。
禁止只确认优势区域。

## 结论规则

- 不把一次胜利解释为算法普适性；
- 不把目标值跨函数相加或平均；
- 每一个“适用范围”声明必须指向函数类别、维度、预算和重复次数；
- 每一个“限制”声明必须保留反例与对照算法结果。
