# FIND-Lite 开源发布简报

## 算法定位

FIND-Lite v0.1.0 是一个无梯度、连续、盒约束、严格预算的随机两点线搜索器。它用 2d 个永久 LHS 参考点维护方向覆盖，每轮沿一条真实参考线评估正反两个点，并按该线成败放大或缩小尺度。

## 已完成实验

阶段一：维度 2--200、预算 50d/100d/500d/1000d 的边界扫描。阶段二：30 个种子，与固定 DE/rand/1/bin、PSO 对照。阶段三：Zakharov、Griewank、Levy、Schwefel、旋转 Rastrigin，10/30 维，20 个新种子，并检查 DE/PSO 参数敏感性。

## 主要结果

- Sphere：至 200 维仍可持续精炼，200D、1000d 中位数约 8.39×10^-24；
- 100D 旋转病态二次：Lite 约 90，固定 DE/PSO 约 4.43×10^6、5.91×10^5；
- 100D Rosenbrock：Lite 约 205，优于本协议固定 DE/PSO，但仍非高精度；
- 30D 平移 Ackley：Lite 约 9.285，明显落后 DE 的 2.70×10^-3；
- 30D 旋转 Rastrigin：Lite 约 35.32，优于本轮四组固定 DE/PSO；
- 30D Zakharov：Lite 约 8.25×10^7，默认 DE 约 37.0，属于严重反例。

## 综合评价

FIND-Lite 的优势是简洁、可解释、预算严格、对单峰和病态方向有较强开发能力。其不足是跨盆地能力弱，对平移、多峰、欺骗性边界和变量耦合高度敏感。

不应宣称全局收敛、通用最优或全面优于 DE/PSO。更准确的公开表述是：FIND-Lite 是适用于部分连续盒约束黑箱任务的轻量级局部线搜索基线，在 Sphere、病态二次及部分旋转景观上具有竞争力。
