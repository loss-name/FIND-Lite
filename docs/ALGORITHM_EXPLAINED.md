# FIND-Lite 完整算法讲解

## 输入与目标

给定目标函数 f:R^d→R 和盒约束 l_i≤x_i≤u_i，在不使用梯度的情况下最小化 f(x)。预算 B 包含所有目标函数评估。

## 初始化

生成 2d 个拉丁超立方点并映射到边界盒内。每个点只评估一次，作为永久参考点。初始最优点为这些参考点中目标值最小者。永久保存使初始高维方向覆盖不会因生存选择被压缩成低秩结构。

## 一次迭代

随机选择参考点 r_j，令当前最优点为 x，定义真实方向 v=r_j−x。该参考点拥有尺度 s_j，构造两个候选 y+=x+s_jv 与 y−=x−s_jv。两点使用同一个迭代开始前的 x，严格属于同一条搜索线。

## 边界处理

若候选超出盒边界，求沿射线可行的最大比例 λ∈[0,1]，使用 x+λs_jv。边界截断只改变前进距离，不改变搜索线方向，避免逐坐标裁剪造成折线。

## 接受和尺度更新

若任一候选优于当前全局最优，则接受其中更好的点，该参考线尺度乘 1.5 并上限为 2；若两个候选都失败，该线尺度乘 0.5 并下限为 1e−15。其他参考线状态不变。

## 预算与复杂度

初始化消耗 2d 次评估。之后每轮最多评估两个候选，总评估次数不超过预算。存储 O(d²) 参考点和 O(d) 尺度，候选生成计算约 O(d)。

## 收敛性质

严格改进规则保证历史最优值序列单调不增。成功时尺度放大，失败时尺度缩小，因此每条参考线具有粗到细的自适应行为。长期失败时会进行局部精炼，但不会自动跳出当前盆地，所以没有全局收敛保证。

## 版本演化所得结论

从 GTS-A/FIND-V 的随机两点线搜索出发；增加三群、退火、成功率和转弯机制后发现收益不稳定；审计发现方向覆盖被种群淘汰破坏；固定真实参考点并修正射线边界后，Sphere 和病态二次出现数量级改善；后续消融确认退火/三锚点只能作为条件性分支，成功档案、周期重建、固定尺度下限和无条件续行均未证明值得进入基线。

## 适用边界

最适合连续、确定性、盒约束、局部结构较平滑且线方向有意义的任务。对平移 Ackley、Levy、Schwefel、Griewank 和高维 Zakharov，实验显示可能明显落后于 DE/PSO。FIND-Lite 是研究型局部线搜索器，不是通用全局优化器。
