# 固定测试协议

所有发布级结果必须报告函数、维度、边界、预算、种子、算法参数、中位数、四分位区间和
完整运行次数。结果以最终目标值计，越小越好。

## 套件

- `smoke`：2、10维；Sphere、Rastrigin、Ackley；用于正确性和预算检查。
- `core`：10、30维；Sphere、平移 Sphere、Rosenbrock、平移 Rosenbrock、Rastrigin、
  平移 Rastrigin、Ackley、平移 Ackley、旋转病态二次；默认30个独立种子、`500d`预算。
- `stress`：维度2、5、10、30、50、100、200；预算`50d`、`100d`、`500d`、`1000d`；
  先用10个种子扫描，再对候选边界增加到30个种子。

## 对照和消融

默认横向对照为 DE/rand/1/bin（`F=0.5`、`CR=0.9`、种群`2d`）和全局最优 PSO
（`w=0.7298`、`c1=c2=1.49618`、群体`2d`）。Lite 使用其定义内的 Latin-hypercube
初始化；须明确该初始化差异。

消融仅改变一个机制：默认 Lite、普通三锚点、退火 Lite。任何新机制必须先在未参与
设计的平移多峰和30维 Rosenbrock 上测试，不得只报告有利函数。
